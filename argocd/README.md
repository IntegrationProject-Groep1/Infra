# ArgoCD Configuration

This directory contains the manifests for installing ArgoCD and defining the GitOps Applications for the ShiftFestival project.

## Directory Structure

- `install.yaml`: The pinned ArgoCD installation manifest (currently v2.11.0). **Do not edit this file manually.**
- `kustomization.yaml`: Manages the ArgoCD installation and applies custom patches (e.g., RBAC, ignoreDifferences).
- `namespace.yaml`: Defines the `argocd` namespace.
- `applications/`: Contains the Application Custom Resource Definitions (CRDs) that tell ArgoCD which Git repos/branches to watch and where to deploy them.
- `image-updater/`: Configuration for the ArgoCD Image Updater, which automates image tag updates in Git.

## Usage

### Installing/Updating ArgoCD
```bash
kubectl apply -k argocd/
```

### Deploying Applications
```bash
kubectl apply -k argocd/applications/
```

## Self-Healing & Sync Policy

ArgoCD is configured with `automated` sync and `selfHeal: true`. This means:
1. Any commit to the watched branch is automatically deployed to the cluster.
2. Any manual changes made to the cluster (drift) are automatically reverted by ArgoCD to match the state in Git.

## Security

- ArgoCD is exposed via a Cloudflare Tunnel at `argocd.desiderius.me`.
- Access is protected by Cloudflare Access (SSO).
- Secrets for Git write-back (used by Image Updater) are managed manually in the `argocd` namespace as `git-creds`.
